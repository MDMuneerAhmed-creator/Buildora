# 🚀 Buildora AI

**Buildora AI** is an AI-powered business planning platform that helps aspiring entrepreneurs discover business ideas, compare opportunities, generate actionable roadmaps, and receive AI-powered guidance for launching and scaling their ventures.

---

## ✨ Features

- 🔐 Secure Firebase Authentication
  - Email & Password Login
  - Google Sign-In
  - Password Reset

- 💡 AI Business Idea Explorer
  - Browse curated business ideas
  - Search and filter opportunities
  - Compare multiple ideas

- 🤖 AI Business Copilot
  - Business planning assistance
  - Market insights
  - Startup guidance
  - Business strategy recommendations

- 📊 Business Roadmaps
  - Financial planning
  - Marketing strategy
  - Operations planning
  - Compliance checklist
  - Growth roadmap
  - Risk assessment
  - Timeline generation

- ❤️ Saved Ideas
- 👤 User Profile Management
- 📱 Responsive Design
- 🌙 Modern Dark UI

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/MDMuneerAhmed-creator/Buildora2.0.git
cd Buildora2.0
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env` file.

```env
VITE_FIREBASE_API_KEY=
VITE_FIREBASE_AUTH_DOMAIN=
VITE_FIREBASE_PROJECT_ID=
VITE_FIREBASE_STORAGE_BUCKET=
VITE_FIREBASE_MESSAGING_SENDER_ID=
VITE_FIREBASE_APP_ID=
VITE_FIREBASE_MEASUREMENT_ID=
VITE_GEMINI_API_KEY=
```

## Run the Development Server

```bash
npm run dev
```

## Build for Production

```bash
npm run build
```
